# Lung Patient Prediction Using Machine Learning

## Project Overview
This project predicts lung patient status using a machine learning model and provides a Streamlit user interface.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- MySQL
- seaborn

## Project Components
- Exploratory Data Analysis (EDA)
- Data preprocessing and visualization
- K-Nearest Neighbors (KNN) model
- Feature scaling
- Streamlit application
- MySQL database integration

## Project Files
- `lungs.ipynb` — EDA and machine learning notebook
- `app.py` — Streamlit application
- `knn_lung.sav` — Trained model
- `scaler_lknn.sav` — Saved feature scaler
- `lung.jpeg` — Application image
- `requirements.txt` — Python dependencies

## How to Run
1. Install the dependencies listed in `requirements.txt`.
2. Configure your MySQL database credentials securely.
3. Ensure the required model and image files are available.
4. Run the application using `streamlit run app.py`.

## Disclaimer
This project is for educational purposes only and is not a medical diagnostic tool.
